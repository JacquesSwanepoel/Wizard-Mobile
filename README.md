# Wizard-Mobile - 2022
The first mobile game I tried to develop.

I worked on this in my senior year of highschool, the idea was I wanted a magic based mobile game that I could show my friends.

The gameplay would be that the player uses a combination of different elements to cast a spell, that would be valid for the scenario. Spellcasting would be done by pressing 5 buttons, each correlating to an element, in a certain sequence to cast a spell.

In the end development didnt get very far, and I had the idea that the player would duel enemy wizards. This ended up being sprites of my friends that I redreq in aseprite (Im still pretty proud of them).

I might work on this idea again someday.
